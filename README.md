# Trang Linh Le - Portfolio

1. Install Node.js 20 LTS (nodejs.org) and Git.
2. In this folder: `npm install` then `npm run dev`, open http://localhost:3000
3. Edit text in `data/content.ts` (search TODO). Colors in `tailwind.config.ts`.
4. Deploy: push to GitHub, then import the repo at vercel.com (framework: Next.js, no settings needed).
